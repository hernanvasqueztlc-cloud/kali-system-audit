# Kali System Audit 🚀

Un script ligero e intuitivo escrito en Bash para realizar una rápida inspección y auditoría de estado en Kali Linux.

## Características
- Muestra versión del Kernel y Hostname.
- Desglosa las direcciones IP activas por interfaz.
- Informa el uso actual de RAM y espacio en disco.
- Lista los servicios y puertos que están escuchando (LISTEN).

## Instalación y Uso

1. Clonar el repositorio:
   git clone https://github.com/hernanvasqueztlc-cloud/kali-system-audit.git
   cd kali-system-audit

2. Otorgar permisos de ejecución:
   chmod +x audit.sh

3. Ejecutar el script:
   ./audit.sh
